# STPIM 試作アプリ

「予定をブロックで積み、横へスライドしてひとつずつクリアする」STPIM のブラウザー試作です。ビルドや外部ライブラリは不要です。`index.html` を開くか、リポジトリのルートで次を実行して `http://localhost:8000/prototype/` を開いてください。

```powershell
python -m http.server 8000
```

初期データを見る場合は `demo` / `demo1234` でログインできます。新しいアカウントも作成できます。

## 含まれる機能

- ログイン・新規登録・ログアウト。ユーザー名をログイン ID とし、登録パスワードは8文字以上、試作セッションは8時間です。
- 月カレンダーと日画面。時間制・優先順位のブロックを別々の積み重ねで表示し、状態や選択した日を確認できます。
- ブロックの作成・編集・削除確認・日付を選んでの複製。
- 右スワイプでのクリア、優先順位ブロックの開始記録、終了時刻の手入力、クリアを1回だけ戻す操作。
- 予定終了との差、タイムアタックの前回記録と自己ベスト、履歴・累計の確認。
- 画面幅に応じたレイアウト、キーボード操作、動きを抑えるOS設定への配慮。

## 仕様を揃えるために採用した判断

- ログイン ID は全資料でユーザー名に統一しました。メールアドレス欄は設けません。
- 状態コードは `TODO` / `DONE` / `MISSED` とし、未処理になるのは終了予定を過ぎた時間制ブロックだけです。優先順位ブロックは未処理になりません。
- タイムアタックは、作成時に選んだ過去のタイムアタック系列にだけつながります。タイトルの一致では系列を結びません。複製時は系列を引き継ぎます。
- 「前回」と「自己ベスト」は、同じ系列の完了記録を実績終了時刻、同時刻ならブロック ID の順で毎回計算します。戻す・削除による古い結果を残しません。ベスト更新は厳密に条件を超えたときだけです。
- 時間制の実績開始は予定開始時刻です。予定開始前にクリアした場合は実績開始を持たせず、所要時間の比較は行いません。優先順位は開始ボタンを押した場合だけ開始時刻を記録します。
- 未来日のブロックは当日になるまで開始・クリアできません。終了時刻の手入力は時間制ブロックで使い、ブロックの日付に時刻を当てはめて未来時刻を拒否します。
- 開始済み・クリア済みブロックは結果の整合性を保つため、タイトルとメモだけ編集できます。日付・積み方・時刻・タイムアタック設定はロックされます。
- 時間制の予定終了との差と所要時間は分単位に丸めます。予定との差は「実績終了 − 予定終了」で、遅れをプラス、早まりをマイナスとして表示します。

## 試作の範囲

アカウント・パスワード・予定・結果はブラウザーの `localStorage` に保存されます。パスワードはこの試作では平文で保存され、データ共有・複数端末同期・サーバー側認証・バックアップには対応しません。本番運用にはサーバー側の認証、パスワードハッシュ化、永続データベース、セッション管理が必要です。

`src/main/webapp` 以下の Java サーブレットは既存のバックエンド検討用コードとして残し、この試作UIとは未接続です。
